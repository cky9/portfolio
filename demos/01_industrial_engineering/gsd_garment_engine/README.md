# 👔 服装 IE - GSD 标准工时拆解、工序报价与产线排单系统

> **商业价值**：传统服装外贸与制衣厂在承接新单时，IE 工程师拆解工序、核算工时需耗费 1~3 天，中小厂往往凭感觉拍脑袋报价，常因报高丢单或报低亏损。本项目基于 **GSD (General Sewing Data)** 国际标准代码库与缝制动素库，实现款式工艺 Tech Pack 的秒级拆解、标准工时 (SMV) 测算、流水线平衡排单与加工费成本核算。
